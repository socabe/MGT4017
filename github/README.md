# Website project

A responsive static website built with HTML, CSS and JavaScript.

## Files
- `index.html` — page content and structure
- `style.css` — layout and responsive styling
- `script.js` — mobile menu, search, demo account dialog and calendar

## Preview locally
Open `index.html` in a web browser. For the best development experience, use Visual Studio Code with the Live Server extension.

## Publish with GitHub Pages
1. Sign in to GitHub and create a **new public repository** (for example, `my-website`).
2. Upload `index.html`, `style.css`, `script.js` and `README.md` to the repository's root folder.
3. Open the repository's **Settings**.
4. Select **Pages** in the left-hand menu.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch **main** and folder **/(root)**, then click **Save**.
7. Wait a few minutes. GitHub will show your published website URL in the Pages section.

## Before launching
- Replace `LOGO`, the sample text, prices and `hello@example.com` with your own details.
- Replace the sample Unsplash images with your own licensed images if preferred.
- The login/sign-up form is a visual demo only. It does not create accounts or store passwords.
- The subscription cards do not take payments. Connect a secure authentication and payment provider before accepting real users.
- The calendar currently displays dates only; it is not connected to an events database.
